# Dear Candidate


As part of our interview process, this assessment is designed to evaluate both your collaborative workflow and your technical problem-solving abilities.
The assessment consists of two connected tasks:

## 1. Git Conflict Resolution
You will resolve a simulated Git conflict within an existing codebase.
This exercise is intended to reflect a realistic team development workflow and evaluate your ability to work within a collaborative engineering environment.
## 2. Rust Coding Challenge
Using the codebase finalized after resolving the Git conflict, you will complete a Rust backend engineering task involving correctness, concurrency, and system behavior.
The overall exercise is designed to assess:
problem-solving ability,
familiarity with collaborative development workflows,
code quality and maintainability,
and technical proficiency in backend/system-level engineering.


Please focus on writing clean, reliable, and production-oriented code.
We look forward to seeing your approach and engineering decisions throughout the assessment.


## 🔧 Installation

1. **Clone the Repository**

   ```bash
   git clone https://github.com/artrade-ref/Assessment.git
   cd Technical-Assessment
   ```

2. **Install Dependencies**

   ```bash
   cargo build
   ```


3. **Run Tests**

   ```bash
   cargo test
   ```
